# 🎯 SentiCode AI

SentiCode AI is a smart sentiment and emotion analysis web app built using **React**, **Framer Motion**, **Firebase Auth**, **Recharts**, and **Google Gemini API**. It allows users to analyze the **tone**, **emotion**, and **confidence level** of any text or webpage — with speech input, real-time graphs, and analysis history.

---

## 🚀 Features

- 🔍 Text or URL sentiment analysis
- 🎙️ Speech-to-text input using mic
- 📊 Graphical charts (bar, pie) for sentiment/emotion breakdown
- 🧠 Gemini AI-powered response summarization
- 📁 History tracking of analyzed entries
- 🔐 Secure login & logout via Firebase Auth
- 🎥 Full-screen background video
- ✨ Clean UI with animated transitions (Framer Motion)
